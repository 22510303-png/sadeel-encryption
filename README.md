# مقدمة

يهدف هذا المشروع إلى تطبيق مفهوم إخفاء البيانات داخل الصور (Steganography) باستخدام لغة Python، وذلك من خلال إخفاء رسالة نصية داخل صورة رقمية بطريقة غير ملحوظة بالعين المجردة.

تم استخدام تقنية Least Significant Bit (LSB) والتي تعتمد على تعديل أقل بت أهمية داخل البكسلات لتخزين البيانات السرية دون التأثير الواضح على جودة الصورة.

# شرح أهم الدوال

## دالة تحويل النص إلى Binary

```python
def text_to_binary(text):
    return ''.join([format(ord(i), "08b") for i in text])
```

### وظيفة الدالة:
تقوم بتحويل كل حرف داخل النص إلى تمثيل ثنائي (Binary) مكون من 8 بتات باستخدام ترميز ASCII.

# شرح تقنية LSB

تعتمد تقنية LSB على تعديل آخر بت داخل قيمة البكسل.

مثال:

```python
10110110
```

يتم تعديل آخر بت فقط:

```python
10110111
```

وبذلك لا يتغير شكل الصورة بشكل ملحوظ، ولكن يتم تخزين البيانات بداخلها.

---

# شرح طريقة التشفير داخل الكود

يتم تنفيذ عملية التشفير باستخدام السطر التالي:

```python
flat_img[i] = (flat_img[i] & 254) | int(binary_data[i])
```

### شرح العملية:

#### أولاً:
```python
flat_img[i] & 254
```

الرقم 254 بالصيغة الثنائية:

```python
11111110
```

تقوم هذه العملية بحذف آخر بت من قيمة البكسل.

---

#### ثانياً:
```python
| int(binary_data[i])
```

تضيف البت الجديد القادم من الرسالة السرية.

---

### النتيجة:
يتم استبدال أقل بت أهمية داخل البكسل ببت من الرسالة النصية.
